Built on Fountain

Fountain is an API for driving AI agents on sandboxes: every agent gets a real computer, every run is a conversation you can stream, schedule, and build products on. Each app below is a small product built almost entirely on that one API — most have no backend of their own at all.

Every app connects the same way: point it at a Fountain server (https://fountain.inevitable.fyi), then Sign in with Fountain (OAuth + PKCE) or paste an API key. Static files in your browser, the Fountain API, and an agent with a computer — that's the whole stack.
